    How it works

    Every board is a node in a graph; sliding a tile is an edge. BFS explores level by level, so it always finds the shortest solution but visits many states. A* orders nodes by moves-so-far + Manhattan distance; because Manhattan never overestimates, A* is still optimal and expands far fewer nodes. Greedy uses only the heuristic — very fast, but solutions can be long.

    Only half of all boards are solvable: a board can reach the goal only if its number of inversions is even. The solver checks this before searching.
